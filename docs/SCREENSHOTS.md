# Screenshots to capture for your GitHub and resume

Launch `python3 api_server.py` and capture real UI screenshots, ideally from a 1440px-wide desktop window:

1. **Overview:** hero, incident metrics, severity distribution, incident table.
2. **Incident center:** severity filtering and detail drawer.
3. **Remediation lab:** generated before/after plan and confirmation workflow, before executing.
4. **Verified result:** after explicitly authorizing and simulating remediation.
5. **Audit trail:** approval and execution records.
6. **Dark theme:** alternative overview screenshot.

Caption them **local portfolio demonstration**, not production AWS telemetry. Avoid images of private credentials or production systems.
